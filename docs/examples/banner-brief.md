## Image prompt

> Create an original wide 3:1 conceptual README banner for Repo Cleaner, an agent skill that improves repository documentation. Show the same documentation becoming easier to understand and use.
>
> Depict two related editorial page compositions: an initially dense page with weak hierarchy, then the same recognizable material organized into a clear title, short purpose, prominent example, and visible starting point. A small linked guide beside the organized page expresses deeper help moved out of the first-use path. Show reorganization rather than deletion or invented application features.
>
> Use the existing light background, charcoal linework, and restrained blue accents. Make the changed hierarchy the focal point, with large simple page forms and generous margins that survive phone-width display. Use a flat editorial illustration. Exact text: “Repo Cleaner”. Put detailed explanation in Markdown outside the image. Exclude tiny body copy, badges, metrics, robots, circuitry, copied marks, browser chrome, and decorative cleaning equipment. This is conceptual artwork, not a screenshot or measured before/after.
